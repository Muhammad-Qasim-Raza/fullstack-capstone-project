# 18-Task Submission Checklist

1. Submit public GitHub URL to `user-story.md`.
2. Create 8+ public GitHub Issues with labels `new`, `icebox`, `technical debt`, or `backlog`; capture as `userstories.png`.
3. Run `cd backend && npm run seed`; save real output as `inserted_items`.
4. Submit public GitHub URL to `backend/db.js`.
5. Submit public GitHub URL to `backend/routes/giftRoutes.js`.
6. Submit public GitHub URL to `backend/routes/searchRoutes.js`.
7. Submit public GitHub URL to `backend/app.js`.
8. Submit public GitHub URL to `sentiment/index.js`.
9. Submit public GitHub URL to `frontend/src/pages/RegisterPage.js`.
10. Submit public GitHub URL to `frontend/src/pages/LoginPage.js`.
11. Submit public GitHub URL to `backend/routes/authRoutes.js`.
12. Deploy the app and capture `deployed_landingpage.png` with the live URL, title, description and Get Started button.
13–17. Run the real cURL commands and save real command/output in `docs/curl/mainpage`, `register`, `login`, `item_detail`, `search_item`.
18. Push `.github/workflows/ci.yml`, wait for a successful GitHub Actions run, and save the real evidence in `docs/CI-CD`.

Do not fabricate screenshots, URLs, terminal output, or CI results. Those parts require your GitHub account,
MongoDB environment, and deployment provider.
