# GiftLink User Stories

1. **Browse gifts:** As a visitor, I want to browse available household items so that I can reuse things instead of buying new ones.
2. **Search:** As a visitor, I want to search by keyword and category so that I can quickly find relevant items.
3. **Item details:** As a visitor, I want to view an item's details so that I can decide whether it is useful.
4. **Registration:** As a new user, I want to register so that I can use authenticated features.
5. **Login:** As a registered user, I want to log in securely so that my account is protected.
6. **Profile:** As a user, I want to update my profile so that my information stays current.
7. **Comments:** As a logged-in user, I want to comment on gifts so that I can communicate with the community.
8. **Security:** As the project owner, I want JWT-protected APIs so that unauthorized users cannot modify protected data.
